# Кабинет восприятия

Интерактивный 3D-атлас «Как устроен разум: восприятие, эмоции, ошибки мышления».
Одностраничный сайт на Three.js без сборки: `index.html`, `style.css`, `main.js`
(Three.js подключается через import map с jsDelivr).

- **Сцена** — комната Эймса: проективно искажённая комната, которая выглядит
  прямоугольной только из «глазка». Кадр проходит через собственный пост-шейдер
  «оп-арт» (полосы переменной толщины, муар от глубины, шахматный фон, выгнутый к курсору).
- **Иллюзия / схема** — переключатель показывает настоящую геометрию и подписи.
- **Линза** под курсором или пальцем снимает оптическое искажение.
- При `prefers-reduced-motion` оптическая анимация останавливается.

## Данные

- `data/content.js` — каталог искажений и карта мозга.
- `data/world.js` — растр карты мира. Сгенерирован один раз скриптом
  `tools/build-world.mjs` из выгрузки IHME Global Burden of Disease 2017
  (через Our World in Data) и границ Natural Earth (`world-atlas`). Сайту скрипт не нужен.

## Локальный запуск

```
python3 -m http.server
```
и откройте http://localhost:8000.

Атлас научно-популярный и не заменяет консультацию специалиста.
